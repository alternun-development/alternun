# ลบบัญชีของคุณ

Alternun มีหน้าลบบัญชีที่เข้าถึงได้ในแอป AIRS พร้อมตัวเลือกภาษาและปุ่มลงชื่อเข้าใช้และการตั้งค่าที่ชัดเจน

## เริ่มคำขอลบบัญชี

1. เปิด [airs.alternun.co/delete-account](https://airs.alternun.co/delete-account)
2. ลงชื่อเข้าใช้บัญชีที่คุณต้องการลบ
3. ตรวจสอบข้อมูลที่ต้องการเก็บไว้ แล้วติดต่อฝ่ายสนับสนุนจากอีเมลที่ลงทะเบียนของบัญชีเพื่อยืนยันและดำเนินการตามคำขออย่างปลอดภัย

หากคุณไม่สามารถลงชื่อเข้าใช้ได้ โปรดติดต่อ [support@alternun.co](mailto:support@alternun.co) และระบุอีเมลที่เชื่อมโยงกับบัญชี
