# Agent Workspace

`.agents/skills/` remains the home for repository agent skills.

The former `.agents/active-tasks`, `.agents/pending-tasks`, and `.agents/done-tasks` workflow is deprecated and archived at `archive/task-workflow/`. Do not create or update task specifications there.

Create and move all task specifications only in [`.specs/`](../.specs/README.md). The migration mapping is at [`.specs/MIGRATION-INDEX.md`](../.specs/MIGRATION-INDEX.md).
